Загальні питання

Зверніть увагу: тут зібрані найважливіші поради для нових власників.

Чи кусаються фаґлери?

Наші фаґлери — виховані монстри. Вони можуть злегка "прикушувати" за палець, але це лише ознака глибокої поваги. Проте, ми не рекомендуємо залишати їх наодинці з гудзиками.

Чим їх годувати?

Найкраща їжа — старі шкарпетки. Також вони обожнюють крихти від печива.

Навчальний процес та IT

Наші студенти також вивчають програмування. Ось приклад коду для привітання нового монстра:


function welcomeFuggler(name) {
  console.log("Привіт, " + name + "! Твої зуби сьогодні блищать.");
}
welcomeFuggler("Гризь");
Чи видається диплом?

Так, кожен студент отримує диплом магістра Гудзикових наук.
